Project 04

House Price Analysis & Prediction | Python

  • Compared Linear Regression and Random Forest on 21,613 housing transactions
  • Best model reached R2 = 0.76 and RMSE around 176,783 USD
  • Key drivers: living area, build quality, bathroom count
More Detail

Goal: Build a machine learning solution to predict housing prices and identify major value drivers.

Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

Implementation

  • Analyzed 21,613 housing transactions with features including price, living area, lot area, bedrooms, bathrooms, floors, and build year.
  • Cleaned missing/duplicate records, converted date fields, and created derived variables such as year, month, and house_age.
  • Performed EDA using histograms, count plots, box plots, correlation heatmaps, and time-based trend charts.
  • Detected outliers, especially in price, bedrooms, sqft_living, sqft_lot, and high-value segments.
  • Compared Linear Regression and Random Forest on both raw and outlier-handled datasets.
  • Evaluated models using R2 and RMSE metrics.

Outcome

  • Random Forest performed better than Linear Regression, indicating non-linear relationships.
  • Best model (Random Forest with 200 trees after outlier handling) reached R2 = 0.76 and RMSE around 176,783 USD.
  • Linear Regression improved to R2 = 0.65 after outlier handling.
  • Most influential factors included living area, build quality, bathroom count, nearby living area, and above-ground area.

Project 05

Book Product Segmentation from Web Data | Python

  • Scraped 1,000 books across 50 categories using BeautifulSoup
  • Applied K-Means (K=4) to segment products by price, rating, and stock
  • Defined 4 clusters: value, low-performing, high-stock-risk, and premium books
More Detail

Goal: Collect and analyze e-commerce book data, then segment products to support pricing and inventory decisions.

Tools: Python, Requests, BeautifulSoup, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, K-Means, PCA.

Implementation

  • Scraped 1,000 products from Books to Scrape across 50 categories.
  • Extracted title, category, price, rating, stock status, stock quantity, description, URL, and image fields.
  • Converted text price to numeric format, parsed availability into stock quantity, and standardized column names.
  • Handled missing values, duplicates, and repeated price records.
  • Ran EDA for price/rating distribution, category volume, average metrics, and inventory trends by category.
  • Standardized key variables and used K-Means clustering with Elbow and Silhouette to select K = 4.
  • Visualized clusters with PCA and profiled average characteristics per segment.

Outcome

  • Produced a clean dataset of 1,000 books, 50 categories, and total stock of 8,585 units.
  • Defined 4 business-oriented clusters: value books, low-performing books, high-stock-risk books, and premium books.
  • Highlighted frequent categories such as Default, Nonfiction, Fiction, Sequential Art, Fantasy, Romance, and Young Adult.
  • Suggested cluster-based pricing, stock control, promotion planning, and recommendation strategies.

Project 06

Salary Prediction | Python

  • Classification model on 32,500+ census records to predict income above 50K
  • Tuned Random Forest reached Accuracy = 85.45% and ROC-AUC = 0.91
  • Key income drivers: education, occupation, working hours, and capital gain
More Detail

Goal: Predict whether annual income is above 50K and analyze the most influential factors behind income level.

Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, K-Means, PCA.

Implementation

  • Cleaned and processed Adult Census Income data with over 32,500 records.
  • Standardized column names, converted "?" to null, removed duplicates, and created age-group and capital-gain/loss indicators.
  • Performed EDA for income relationships with age, working hours, education, occupation, nationality, and capital gain/loss.
  • Applied K-Means segmentation and PCA visualization for income-related profile exploration.
  • Built preprocessing pipeline with StandardScaler for numeric features and one-hot encoding for categorical features.
  • Trained Logistic Regression and Random Forest with GridSearchCV hyperparameter tuning.
  • Evaluated by Accuracy, Precision, Recall, F1-score, ROC-AUC, and PR-AUC.

Outcome

  • Found class imbalance: income <= 50K at about 75.9%, income > 50K at about 24.1%.
  • Key factors for higher income included middle age, higher education, longer working hours, managerial/specialized occupations, and capital gain.
  • Tuned Logistic Regression reached ROC-AUC = 0.9139, Recall = 85.18%, and F1-score = 69.65%.
  • Tuned Random Forest reached Accuracy = 85.45%, Precision = 81.84%, and ROC-AUC = 0.9114.
  • Proposed model use for high-income lead targeting and potential income-based customer segmentation.
